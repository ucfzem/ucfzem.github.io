# إنجيل برنابا — إصدار ويب (PWA)

تطبيق ويب عربي (RTL) لقراءة إنجيل برنابا بالترجمة العربية للدكتور خليل سعادة (طبعة دار المنار ١٩٠٨م).
يعمل دون اتصال، يدعم البحث الفوري مع تلوين النتائج وعدّاد وتنقّل، فهرس جانبي، تبديل النمط (فاتح/داكن)، التحكم بحجم الخط، شريط التقدّم، زر الرجوع لأعلى، ورابط ذو هاش (`#chapter-N`).

## ملاحظات
- النص يُعرض كما هو في المصدر دون زيادة؛ المصدر: موقع «المعرفة» (sources.marefa.org).
- ٢٢٢ فصلًا؛ يتفرّع المحتوى داخل كل فصل إلى فقرات للقراءة المريحة.
- يتم تخزين الإعدادات والتقدّم محليًا في المتصفّح (`localStorage`).

## التشغيل محليًا
افتح `index.html` مباشرةً أو شغّل خادمًا محليًا:
```bash
cd /tmp/opencode/barnabas-app
python3 -m http.server 8000
# افتح http://localhost:8000
```
