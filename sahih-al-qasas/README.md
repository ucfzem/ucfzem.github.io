# صحيح القصص النبوي — PWA Reader

قراءة كتاب **«صحيح القصص النبوي»** للدكتور عمر سليمان الأشقر رحمه الله، مع بحث فوري وفهرس وتنقّل بين القصص، ويعمل دون اتصال (PWA).

## المميزات
- واجهة عربية RTL كاملة، وضع نهاري/ليلي (يُحفظ في `localStorage`).
- فهرس القصص + بحث شامل مع تلوين النتائج وعدّاد وتنقّل بين المواضع.
- تحكم بحجم الخط (A− / A / A+)، شريط تقدّم القراءة، زر العودة للأعلى.
- توجيه بالـ hash (`#story-N` و`read/N`)، ونسخ القصة.
- دعم كامل دون اتصال عبر Service Worker.

## البنية
- `index.html` — الهيكل الأساسي.
- `styles.css` — التنسيقات والثيمات.
- `app.js` — منطق القراءة والبحث والتوجيه.
- `sw.js` — Service Worker للعمل دون اتصال.
- `manifest.webmanifest` — بيانات التطبيق (PWA).
- `data/sahih-al-qasas.json` — نص القصص.

## بنية البيانات
```json
{
  "bookInfo": { "title": "...", "author": "...", "language": "ar", "direction": "rtl" },
  "stories": [ { "id": 1, "number": 1, "title": "...", "content": "...", "summary": "..." } ]
}
```

## ملاحظة عن النصوص
النصوص المعروضة في `data/sahih-al-qasas.json` مختارات من الأحاديث الصحيحة الواردة في كتب السنة (البخاري ومسلم وغيرها)، مثبتة كما هي في مصادرها الأصلية مع ذكر المصدر. لعرض نص الكتاب كاملاً، استبدل/أضف السطور في الملف بنفس البنية (راجع أدوات التحويل في `tools/` إن وُجدت).
