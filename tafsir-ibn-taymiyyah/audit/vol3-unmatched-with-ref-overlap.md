# Volume 3 — Qur’an quote overlap review

Generated: 2026-10-23 · Corpus: **quran-uthmani** · Scope: **volume 3**

This list covers **closed `﴿...﴾` quotes that have a parsable reference and still fail the 1–3 ayah exact match**. It does **not** cover the much larger bracket-integrity problem: volume 3 currently has **2,050 opening `﴿` vs 878 closing `﴾`**, with **1,164 content items unbalanced**.

Method: for each quote, candidate runs of 1–5 ayahs around the cited reference were scored. The reported run maximizes F1 between the quote token set and the run token set. `recall=|Q∩R|/|Q|` is the requested “how many of the quote’s words appear in the candidate run”; `precision=|Q∩R|/|R|`; `ratio` is sequence similarity. A separate check against `quran-simple` marks script variants that are not corruption.

**Status note:** the earlier 111-fix commit (`694c7b4`), the 7:187/2:282 fix (`868df90`), and the 6:4–11 fix (`0c61cd7`) are already on `origin/main`. This report makes no text changes.
